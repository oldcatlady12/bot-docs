Versus Invites Bot

Overview

Versus Invites combines two systems into one bot: a competitive King of the Hill invite battle game and a global server partnership listings hub. Servers compete to hold the throne by out-inviting each other, guessing secret numbers, and spending coins on perks — while the partnership system lets servers list themselves across 4 categories for cross-server discovery and collaboration.

👑 King of the Hill — Invite Battles

Servers compete to hold the top position by earning more invites than the current holder. The holder picks a secret number — challengers guess it to dethrone them. Earn coins for correct guesses, spend them on perks, and climb the leaderboard.

🤝 Global Partnership Listings

Servers submit themselves to 4 global categories (Partnership, Staff, Work, Boosts). Applications go through admin approval, then appear in a live-updating embed in your server's partner channel. Any Discord server can browse all listings.

👑

Secret Number Game

Holder sets a number 1–100. Challengers guess — hot/cold hints given. Correct guess = dethroned

💰

Coin Economy

Earn coins for correct guesses and tips from other users. Spend on role perks

🏆

Perk Roles

Admins assign roles as perks — users buy them with coins earned from battles

📈

Persistent Leaderboard

Paginated leaderboard tracking all-time invite counts, wins, and coin balances

🤝

4-Category Listings

Servers list themselves across Partnership, Staff, Work, and Boost categories

✅

Admin Approval Queue

All partnership applications are reviewed by admins before going live

Partnership Categories

Servers can submit listings to any of these 4 global categories:

🤝 Partnership

General server partnerships — mutual promotions, co-events, and cross-community collaboration

👨‍💻 Looking for Staff

Servers actively recruiting moderators, admins, or other staff positions

💼 Looking for Work

Individuals or servers offering Discord services — moderation, design, bot development, etc.

🔥 Looking for Boosts

Servers seeking Nitro boosts — can offer perks, roles, or other incentives in exchange

Commands — Invite Battles (KOTH)

Setup Admin Only

CommandDescription
/setupInitialize Invite Battles for this server — creates database entries and shows config instructions
/config channel add #channelSet the channel where game activity is posted
/config approval #channelSet the channel where new invite submissions are reviewed
/config perks addAssign a Discord role as a purchasable perk (users spend coins to buy)
/config coins <amount>Set how many coins a user earns per correct secret number guess
/config guesses <limit>Set the daily guess limit per user (default: 5)
/config cooldown <hours>Set the cooldown period after activation (default: 3 hours)
/resetReset the current game — clears the active holder and secret number
/forcepick <invite>Admin: force-set a specific server invite as the current target

Setup Guide

Step 1 — Create a Discord Application

Go to the Discord Developer Portal, create a new application named "Versus Invites", go to the Bot tab, copy the token. Under OAuth2 → URL Generator, select scopes: bot, applications.commands. Invite the bot to your server.

Step 2 — Configure .env

DISCORD_TOKEN=your_bot_token_here CLIENT_ID=your_application_client_id GUILD_ID=your_server_id

Step 3 — Install and Deploy Slash Commands

cd versus-invites-bot npm install # Deploy slash commands to your server (guild-scoped, instant) node deploy.js --dev # Start the bot node index.js

Step 4 — Configure in Discord

# Invite Battles setup /setup /config channel add #invite-battles /config approval #invite-approvals # Partnership setup /partner set-channel #partnerships /partner set-admin-channel #partner-applications
