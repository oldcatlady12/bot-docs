Media Recommendation Bot

Overview

Watchlist bot mode (2026-09-16)

Recommendations now live only inside the Tv Kitty app and website (Top Recommended). In Discord this bot keeps: the submission channel (a personal watchlist channel for everyone; app testers can also recommend), the Games forum for upcoming and released games, content requests and the approval channel. The per-category recommendation forums, the general Upcoming forum and Random Weekly Picks are retired.

The Media Recommendation Bot is a comprehensive recommendation tracking system for Discord servers. Members can recommend and vote on various types of media including games, movies, TV shows, anime, manga, and more. Features automatic forum organization, voting, an approval system, Tv Kitty content requests, and optional Google Calendar integration for unreleased media.

Setup Commands Admin Only

!teardown_recommendation_channelsOne-time cleanup (2026-09-16): deletes every per-category recommendation forum, the general Upcoming forum and the Random Picks forum/threads after a confirmation. Keeps the submission channel and the Games forum.

Tv Kitty Content Requests Admin Only NEW

Requests to add a title to the Tv Kitty library (from the Tv Kitty app's Request to Add, or typed into the request channel) become cards in one channel. Members 👍 a card to get pinged; an admin presses "I'll download this" to claim it; the bot deletes the card and pings everyone once the title shows up in the library. No admin approval step.

New Features

Split Category Detection

The bot now automatically detects and categorizes media more accurately:

  • Anime Movies vs Anime TV - Anime films (e.g., Studio Ghibli movies) go to anime_movies, while series go to anime_tv
  • Cartoon Movies vs Cartoon TV - Western animated films (e.g., Pixar, Disney) go to cartoon_movies, while series go to cartoon_tv
  • Documentary Films vs Docuseries - Documentary movies go to documentary_films, documentary series go to docuseries

Deletion Notifications

When forum posts or threads are manually deleted by admins:

  • If a notification channel is set, the bot sends an alert with "Delete from Database" and "Keep in Database" buttons
  • Admins can choose to remove the entry from the database or keep it for potential re-submission
  • Bulk deletion notifications when an entire forum channel is deleted

Reorganize Command

Use !reorganize report to analyze all recommendations and find any that should be moved to different categories. Then use !reorganize execute to automatically move them.

Setup & Configuration

Installation

# Navigate to bot directory cd media-recommendation-bot # Create virtual environment python -m venv venv # Activate venv (Windows) .\venv\Scripts\activate # Install dependencies pip install -r requirements.txt # Configure .env file # DISCORD_TOKEN=your_token_here # OMDB_API_KEY=your_omdb_key (optional) # RAWG_API_KEY=your_rawg_key (optional) # Run the bot python bot.py

Bot Permissions

The bot requires these permissions:

  • Manage Channels - Create forum channels for categories
  • Send Messages - Post recommendations and request cards
  • Create Public Threads - Create genre threads in forums
  • Send Messages in Threads - Post in forum threads
  • Manage Messages - Edit and clear request cards
  • Read Message History - Track existing recommendations
  • Add Reactions - Vote button functionality
