Media Recommendation Bot

Overview

Watchlist bot mode (2026-09-16)

Recommendations now live only inside the Tv Kitty app and website (Top Recommended). In Discord this bot keeps: the submission channel (a personal watchlist channel for everyone; app testers can also recommend), the Games forum for upcoming and released games, content requests and the approval channel. The per-category recommendation forums, the general Upcoming forum and Random Weekly Picks are retired.

Game Watch (2026-10-17)

One pinned panel in the games forum's Gaming Hub post lists every game suggested in the forum (a post with a YouTube trailer counts as one game). Members pick a game from the dropdown and get a private card: watch the trailer, talk about it, gameplay videos, Wishlist on Steam, platforms, release status, and Add to my watch list (their !gamelist). The Suggestions bot still runs the forum and its votes; Game Watch only reads those posts and sorts the panel by votes, then newest. Fully released games move to a second panel with the same dropdowns and buttons in the Games news forum's Out, Watching, Recommend post. See Game Watch below.

Gaming Showcases (2026-10-17)

The full-length YouTube videos of gaming showcases - The Game Awards, Summer Game Fest, Xbox, PlayStation, Nintendo Directs, the PC Gaming Show and more - are posted in the Games news forum's Gaming Showcase post once each show is over. New and recent shows only. See Gaming Showcases below.

The Media Recommendation Bot is a comprehensive recommendation tracking system for Discord servers. Members can recommend and vote on various types of media including games, movies, TV shows, anime, manga, and more. Features automatic forum organization, voting, an approval system, Tv Kitty content requests, and optional Google Calendar integration for unreleased media.

Game Watch Admin Only NEW

Runs on its own once set up. The Suggestions bot reposts every member's post in the games forum with vote buttons; Game Watch reads the repost and never edits or deletes the Suggestions bot's messages or anyone's posts.

  • New post: reads the first YouTube link (the trailer), finds the game on Steam (name, release status, genres, developer, art, wishlist link) and adds missing genre tags to the post. It never removes tags and stops at Discord's 5. A post without a trailer gets one reply asking for the link; the game is still looked up from the post's title.
  • Gameplay: up to two gameplay videos per game from YouTube, posted in the Gameplay Clips post and shown on the game's card. Checked again every week while a game has fewer than two.
  • Daily check: Steam release status and announcements. An Early Access launch is announced in the post, a full release closes the post, and a major update or re-release reopens it.
  • Released games: a second panel with the same dropdowns and buttons, in the Games news forum's Out, Watching, Recommend post, lists the fully released games. The Gaming Hub panel keeps the games still to come (Coming soon, Early Access, status unknown). A game moves across by itself when the daily check sees it release, and each panel links to the other.
  • Gaming Hub on top: the Suggestions bot holds the forum's one pinned post, so the Gaming Hub post can't be pinned. Instead, after anything is posted elsewhere in the forum, the bot sends a silent, empty message in the Gaming Hub post and deletes it at once, which moves the post back to the top. This only works while the forum's Default Sort Order is Recently Active; under Date Posted the bot doesn't bump. !gamewatch status shows whether it's on and when it last bumped.
  • Cost: free. YouTube's free API quota (Game Watch stops at 3,000 of the 10,000 daily units) and Steam's public store and news pages, which need no key.
CommandDescription

!gamewatch setup <forum> <panel post> <clips post>The games forum, the post that holds the panel, and the Gameplay Clips post (mentions, links or ids). Already set up for the games forum.
!gamewatch rescanRe-read every post in the forum and rebuild the panel.
!gamewatch fix <post> <Steam link, app id or name>Correct a wrong Steam match. The corrected match is kept from then on.
!gamewatch hide <post> / showTake a game off the panel or put it back. The post stays.
!gamewatch ignore <post>A post that isn't a game. It's never listed or tagged.

!gamewatch released <post>The post that holds the released games' panel. Set to the Games news forum's Out, Watching, Recommend post.
!gamewatch statusThe setup, how many games and clips, today's YouTube use, and whether the Gaming Hub post is being kept on top.

Gaming Showcases Admin Only NEW

Runs on its own. Every 2 hours the bot looks at the newest uploads of 15 YouTube channels - The Game Awards (which also streams Summer Game Fest and Opening Night Live), Xbox, PlayStation, Nintendo of America, Ubisoft, Capcom USA, PC Gamer (the PC Gaming Show), Future Games Show, Wholesome Games, Devolver Digital, Tokyo Game Show, Day of the Devs, Annapurna Interactive, Limited Run Games and IGN - and posts each new showcase in the Games news forum's Gaming Showcase post: the show's name, the channel, how long it runs and when it streamed, with the YouTube player under it.

  • Full shows only: the title has to name a showcase (Showcase, Direct, State of Play, The Game Awards, Summer Game Fest, Opening Night Live, Games Show...) and nothing like a trailer, recap, reaction, pre-show or gameplay video, and the video has to be at least 18 minutes long.
  • New and recent only: nothing from more than 14 days ago is posted. A live stream or premiere waits until it has ended, so the full video is what gets shared.
  • Once per show: when IGN co-streams a show the organiser also posts, only one of them is shared, the organiser's when both arrive together.
  • Cost: free. YouTube's public channel feeds weren't working, so it uses YouTube's free API quota - about 200 units a day, counted inside Game Watch's 3,000-unit daily cap.

New Features

Split Category Detection

The bot now automatically detects and categorizes media more accurately:

  • Anime Movies vs Anime TV - Anime films (e.g., Studio Ghibli movies) go to anime_movies, while series go to anime_tv
  • Cartoon Movies vs Cartoon TV - Western animated films (e.g., Pixar, Disney) go to cartoon_movies, while series go to cartoon_tv
  • Documentary Films vs Docuseries - Documentary movies go to documentary_films, documentary series go to docuseries

Deletion Notifications

When forum posts or threads are manually deleted by admins:

  • If a notification channel is set, the bot sends an alert with "Delete from Database" and "Keep in Database" buttons
  • Admins can choose to remove the entry from the database or keep it for potential re-submission
  • Bulk deletion notifications when an entire forum channel is deleted

Reorganize Command

Use !reorganize report to analyze all recommendations and find any that should be moved to different categories. Then use !reorganize execute to automatically move them.

Bot Permissions

The bot requires these permissions:

  • Manage Channels - Create forum channels for categories
  • Send Messages - Post recommendations and request cards
  • Create Public Threads - Create genre threads in forums
  • Send Messages in Threads - Post in forum threads
  • Manage Messages - Edit and clear request cards
  • Read Message History - Track existing recommendations
  • Add Reactions - Vote button functionality
