NFL Fantasy Intel Bot

Overview

The NFL Fantasy Intel Bot continuously collects fantasy football intelligence from RSS feeds, websites, and a Discord Twitter relay channel. Every 6 hours, Claude AI reads and synthesizes all new articles, then updates a living Google Doc with organized analysis across 9 sections — draft rankings, injury history, strength of schedule, coaching changes, rookie breakdowns, sleepers/busts, strategies, and waiver wire advice.

Living Google Doc — 9 Sections

The bot maintains one continuously-updated Google Doc with the following sections. Claude rewrites each section as new information arrives:

🏆 Draft Rankings

Overall rankings and positional tiers updated throughout the offseason and season

🩹 Injury Reports

Current injuries, practice participation, and return timelines for key players

📈 Strength of Schedule

Remaining schedule difficulty by position — who has favorable matchups coming up

👨‍🏫 Coaching Changes

New offensive coordinators, scheme changes, and how they affect fantasy value

🆕 Rookie Breakdowns

Rookie class analysis, ADP vs. value, and role projections

💡 Sleepers & Busts

Undervalued players to target and overvalued players to fade

🧠 Fantasy Strategies

Draft strategies, trade advice, and lineup-setting tips

🔄

Waiver Wire

In-season waiver pickups, streamers, and adds by position

📰 General News

Miscellaneous NFL news relevant to fantasy — depth chart changes, suspensions, etc.

Commands

Configuration Commands Admin Only

CommandDescription
!setchannel submissions #channelSet the channel where users submit source tips (via !suggest)
!setchannel updates #channelSet the channel where the bot posts update summaries after each sweep
!setchannel twitter #channelSet the channel where your Twitter relay bot posts — the bot reads these messages
!setdoc <doc_id>Set the Google Doc to update. Accepts either the doc ID or the full Google Docs URL
!botconfigShow the current bot configuration — channels, doc link, and source count

Source Management Admin Only

CommandDescription

!sourcesList all active sources with their IDs and last-checked times
!removesource <id>Deactivate a source by ID
!sweepManually trigger a source sweep right now instead of waiting for the 6-hour interval

Setup Guide

Step 1 — Google Service Account

Create a service account in Google Cloud Console, download the JSON credentials file, and rename it service_account.json in the bot folder. Create or open a Google Doc and share it with the service account email as Editor.

Step 2 — Configure .env

DISCORD_TOKEN=your_bot_token_here ANTHROPIC_API_KEY=your_anthropic_key_here GOOGLE_DOC_ID=your_google_doc_id_here GOOGLE_CREDS_FILE=service_account.json COMMAND_PREFIX=!

Step 3 — Install and Start

cd nfl-fantasy-intel-bot py -3.10 -m venv venv310 .\venv310\Scripts\pip install -r requirements.txt .\venv310\Scripts\python -u bot.py

Step 4 — Configure in Discord

!setchannel submissions #source-suggestions !setchannel updates #fantasy-intel-updates !setchannel twitter #twitter-relay !setdoc YOUR_GOOGLE_DOC_ID

Enable Message Content Intent

In the Discord Developer Portal, go to your bot application → Bot → Privileged Gateway Intents and enable MESSAGE CONTENT INTENT. This is required for the bot to read messages in the Twitter relay channel.

Required Bot Permissions

  • Send Messages
  • Read Message History
  • Embed Links
  • Add Reactions
  • Message Content Intent (Privileged — must be enabled in Developer Portal)

How to Find Your Google Doc ID

Open your Google Doc. Look at the URL — it will look like this:

https://docs.google.com/document/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms/edit

The bold part between /d/ and /edit is your Doc ID. You can paste either just the ID or the full URL into !setdoc — the bot handles both.
